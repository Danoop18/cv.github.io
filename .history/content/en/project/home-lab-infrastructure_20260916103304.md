### Architecture and Tools
- **Home Assistant**: Central automation hub for device control and monitoring.
- **Docker**: Containerized service isolation for local utilities and network tools. - **Linux / Raspberry Pi**: Low-power server running 24/7.

### Focus
Local data privacy, system reliability, and automated alerts for home network metrics.
