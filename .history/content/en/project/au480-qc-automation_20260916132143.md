### Problem

QC data from the AU480 analyzer required manual extraction and handling across multiple weekly sessions, consuming at least 2–3 hours of manual data curation. The process was repetitive, error-prone, and hindered consistent monitoring of analyzer performance. Any variation in manual handling introduced noise that obscured genuine QC trends. Since the operation relied on external infrastructure, there was no automatic local integration for internal data analysis.

### Solution

A Python-based automation system that extracts raw quality control records, processes them through a Pandas pipeline to generate structured outputs, and automatically uploads them to the external analysis platform (app.cclabcontrol.com) using Selenium. This enables real-time performance monitoring and review from any web-enabled device.

### Technology

- **Python**: Core scripting logic, parsing, and data processing.
- **Selenium**: Automated interaction with the database interface.
- **Pandas**: Cleaning, normalization, and generation of clean, structured outputs.

### How It Works

1. Raw data is extracted from the local AU480 analyzer system.
2. Records are loaded into a Pandas DataFrame and cleaned: inconsistent formats are normalized, duplicates are removed, and expected fields are validated.
3. Selenium initiates an automated session and uploads the processed records to the analysis web app (app.cclabcontrol).
4. The platform generates structured tables ready for QC review and trend analysis, eliminating the need for manual reformatting.

- **Metric**: Processes weekly batches of over 100 analytes per day in approximately 1 hour.
- **Impact**: Eliminated repetitive manual data handling. QC monitoring became consistent and reproducible: the same process runs the same way every week, regardless of who executes it.

### Evidence

- Active implementation in the Hospital MAC clinical laboratory.
- Code maintained in a personal repository.
