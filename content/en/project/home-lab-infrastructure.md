`Personal` / `Work in Progress`

### Overview
Independent home lab setup configured on single-board hardware (Raspberry Pi / Linux node) to self-host local network services, home automation routines, and sensor data collection.

### Architecture & Tools
- **Home Assistant**: Centralized automation hub for local device control and sensor monitoring.
- **Docker**: Containerized service isolation for local utilities and network tools.
- **Linux / Raspberry Pi**: Single-board low-power server setup operating 24/7.

### Focus
Local data privacy, system reliability, and automated alerts for home network metrics.
